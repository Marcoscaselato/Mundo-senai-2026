## 📘 Sobre o Projeto

A **Lógica de Programação** é a base universal para a criação de qualquer software. Este projeto foi concebido para transformar a explicação teórica em uma experiência visual e interativa. Utilizando o conceito de "receita de bolo" para introduzir algoritmos, os visitantes e alunos podem interagir diretamente com conceitos de variáveis, estruturas condicionais e laços de repetição.

---

## 🎓 Conteúdo Apresentado

1. **Tema 1: O que é Lógica de Programação?**
   - Conceito de algoritmo e passos finitos.
   - Fluxograma interativo com tomada de decisões.
2. **Tema 2: Variáveis e Tipos de Dados**
   - Analogia das "caixas etiquetadas".
   - Tipos de dados: Texto, Número e Lógico.
3. **Tema 3: Estruturas de Controle**
   - Condicionais: `SE / SENÃO` (Simulação de sistema de notas).
   - Repetição: `ENQUANTO` (Simulação de contador de vidas de um jogo).
4. **Tema 4: A Lógica é Universal**
   - Comparativo de sintaxe da mesma regra lógica em **Python**, **JavaScript** e **Java**.

## ⚡ Funcionalidades e Interatividade

- **Navegação por Slides:** Controle por botões em tela ou pelas setas do teclado (`←` / `→`).
- **Fluxograma Dinâmico:** Geração progressiva de blocos com rolagem automática.
- **Quiz de Tipos de Dados:** Minijogo para teste rápido de identificação do tipo de dado (*String*, *Integer/Float*, *Boolean*).
- **Simulador de Nota (`SE / SENÃO`):** Controle deslizante (*slider*) com alteração imediata do status de aprovação.
- **Loop de Vidas (`ENQUANTO`):** Simulação de laço em tempo real com controle de vidas e rotação animada de engrenagens.
- **Alternador de Sintaxe:** Comparação ao vivo do código em diferentes linguagens de programação.
- **Design Responsivo & Acessível:** Animações otimizadas com suporte a `prefers-reduced-motion` e visual adaptável para telas móveis.

## 🛠️ Tecnologias Utilizadas

- **HTML5:** Estrutura semântica dos slides e componentes.
- **CSS3:**
  - Variáveis CSS (Custom Properties) para consistência da paleta institucional.
  - CSS Grid e Flexbox para layouts adaptativos.
  - Animações `@keyframes` (rotações, *pulses* e *flow* de circuitos).
  - Tipografia via Google Fonts (*Libre Baskerville*).
- **JavaScript (Vanilla ES6+):**
  - Gerenciador de navegação e ciclo de vida dos slides.
  - Renderização dinâmica dos elementos SVG (Engrenagens com `viewBox`).
  - Lógica das interações e simulações em tempo real.
- **Render:** Plataforma de hospedagem da aplicação web.
